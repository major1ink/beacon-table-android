Первая версия: Beacon Table на телефоне и планшете своим приложением, а не вкладкой браузера.

- Подключение к столу ведущего: столы в той же Wi-Fi сети находятся сами, последние серверы запоминаются, адрес можно вписать вручную.
- Работает по обычному http в локальной сети — без сертификатов и предупреждений браузера.
- Стол во весь экран, без адресной строки; экран не гаснет, пока открыт стол.
- «Назад» закрывает окна стола, а со стола уводит только после вопроса.
- Загрузка файлов (аватары, токены, импорт), скачивание выгрузок, ссылки наружу — во внешний браузер.
- Сервера в приложении нет, интерфейс приходит со стола: после обновления сервера приложение обновлять не нужно.

Нужен Android 10 или новее. Проверить файл — `checksums.txt` рядом.
