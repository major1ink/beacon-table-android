# Beacon Table для Android

Приложение, чтобы играть в [Beacon Table](https://github.com/major1ink/Beacon-Table) с телефона или планшета.

Сервера в приложении нет: стол по-прежнему запускает ведущий, а приложение к нему подключается. Вписываете адрес, который показывает ДМ (дома обычно что-то вроде `192.168.1.10:8080`), и стол открывается во весь экран.

Чем это лучше вкладки в браузере:

- работает по обычному http в локальной сети, без сертификатов;
- экран не гаснет, пока открыт стол;
- кнопка «Назад» закрывает окна стола, а не уводит с него;
- нет адресной строки и жестов браузера поверх карты;
- приложение помнит последние серверы.

Интерфейс — тот же, что в браузере: его отдаёт сервер, так что после обновления сервера обновлять приложение не нужно.

## Установка

Скачайте `.apk` из [последнего релиза](https://github.com/major1ink/beacon-table-android/releases/latest). Нужен Android 10 или новее.

## Сборка

Нужны JDK 25 и Android SDK (проще всего поставить Android Studio).

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Поставить на телефон с включённой отладкой по USB: `./gradlew installDebug`.

Отладочная сборка разрешает отладку WebView: откройте `chrome://inspect` в Chrome на компьютере.

## Для сервера

Приложение дописывает к User-Agent `BeaconTableApp/<версия>` — по нему фронтенд стола узнаёт, что открыт в приложении, и прячет то, что здесь не работает (например, вынос окна в отдельное окно браузера).
